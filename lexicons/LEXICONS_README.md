# Lexicon Files for the News Conventionality Index (NCI)

This folder contains the lexicon files used by `News_Conv_Features.R` to extract linguistic features for constructing the News Conventionality Index (NCI).

The NCI feature extraction logic is language-agnostic, but these lexicons are language-specific. The current repository includes a Norwegian-oriented configuration as an example.

All lexicon files should contain:

- One lexical item per line
- No quotation marks
- Blank lines are ignored
- Lines beginning with `#` are treated as comments and ignored

---

## 1. Core Lexicons (Required)

These files are required for full feature extraction:

### Epistemic / Reporting

- `modal_terms.txt`
- `hedge_single.txt`
- `hedge_multi.txt`
- `report_single.txt`
- `report_multi.txt`

### Discourse Connectives (Argumentative)

- `discourse_connectives_single.txt`
- `discourse_connectives_multi.txt`

### Narrativity

- `narrativity_single.txt`
- `narrativity_multi.txt`

### Temporal Anchoring

- `deixis_temporal_single.txt`
- `deixis_temporal_multi.txt`

### Temporal Sequencing (used in narrativity)

- `temporal_seq_single.txt`
- `temporal_seq_multi.txt`

### Style / Emotional Intensity

- `intensifiers.txt`
- `particles.txt`

These lexicons are necessary to compute epistemic, discourse, temporal, and stylistic features.

---

## 2. Optional Sentiment Lexicons (Norwegian Example)

The Norwegian implementation optionally uses fullform sentiment lexicons from **NorSentLex**:

https://github.com/ltgoslo/norsentlex

Expected filenames:

- `Fullform_Positive_lexicon.txt`
- `Fullform_Negative_lexicon.txt`

Important:

- These files are **not included** in this repository.
- If they are not present, sentiment-based features (`polarity_net`, `subjectivity`) are set to 0 and the script will issue a warning.
- NorSentLex is Norwegian-specific.
- For other languages, you must provide an appropriate sentiment lexicon (or omit sentiment features).

If you use NorSentLex resources, please cite the NorSentLex project.

---

## 3. Automatically Generated File (Cache)

- `vivid_mwe_from_collocations.txt`

This file is automatically generated by the script during the first run if it does not already exist.

It stores high-PMI multiword expressions identified via collocation analysis and is used to speed up subsequent runs.

The list is built from the corpus being analysed and is therefore not included in the repository. You may delete this file at any time; it will be regenerated. **Delete it before running the scripts on a different corpus**, so that the list is rebuilt from the new texts.

---

## 4. Adapting to Another Language

To apply the NCI to a different language:

1. Replace all lexicon files in this folder with equivalent lists for the target language.
2. Keep the same filenames so the script can locate them.
3. Adjust any language-specific heuristics in `News_Conv_Features.R` if necessary (e.g., suffix-based adjective/adverb detection).

The NCI framework itself is not language-bound; only the lexicons are.
